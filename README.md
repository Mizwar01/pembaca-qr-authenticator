# 🔍 Pembaca QR Authenticator

Alat berbasis browser untuk membaca QR code 2FA (termasuk format migrasi Google Authenticator) dan mengekstrak nama akun, issuer, serta secret key-nya — 100% berjalan di sisi browser, tanpa server.

## Cara Pakai

Buka: https://mizwar01.github.io/pembaca-qr-authenticator/

Klik **Choose File**, pilih gambar QR code 2FA. Hasil (nama akun, issuer, secret) langsung tampil.

## Keamanan

Semua proses terjadi lokal di browser, tidak ada data terkirim ke server. Secret key bersifat sensitif — jangan dibagikan sembarangan.
